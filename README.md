# card-budget-rules

**남은돈** 안드로이드 앱이 카드 결제 알림을 읽을 때 쓰는 규칙입니다.

남은돈은 결제 내역을 휴대폰 안에만 저장하고 어디에도 보내지 않습니다. 앱이 인터넷을 쓰는 곳은 단 하나, 이 저장소의 `bundle.json`을 **받는** 것뿐입니다. 그래서 앱이 무엇을 받는지 누구나 볼 수 있도록 이 저장소를 공개합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `bundle.json` | 앱이 받는 파일. 규칙(`rules`) + 시험용 샘플 알림(`samples`) + 버전(게시 시각) |
| `bundle.json.sig` | `bundle.json`의 서명 (ECDSA P-256, SHA-256) |
| `source/card_rules.json` | 사람이 읽기 쉬운 규칙 원본 |
| `source/samples.json` | 규칙 시험에 쓰는 샘플 알림 (이름·카드번호는 가림) |

## 앱이 규칙을 받는 방법

1. 12시간에 한 번 `bundle.json`과 `bundle.json.sig`를 받습니다.
2. 앱에 들어 있는 공개키로 **서명을 확인**합니다. 다른 사람이 파일을 바꾸면 앱이 받아들이지 않습니다.
3. 버전이 지금 쓰는 규칙보다 새로울 때만, 함께 든 샘플 알림으로 **스스로 시험**합니다. 하나라도 틀리면 버리고 기존 규칙을 그대로 씁니다.
4. 통과하면 적용합니다. 앱 설정에서 자동 업데이트를 끌 수 있습니다.

이 저장소의 파일은 비공개 개발 저장소의 CI가 샘플 검증을 통과한 뒤 자동으로 게시합니다. 직접 수정하지 않습니다.
